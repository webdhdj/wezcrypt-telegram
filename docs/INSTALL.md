# التثبيت على iPhone + قيود التوقيع والخدمات

> لا يوجد IPA بعد — يظهر هنا بعد بناء ناجح على Mac (انظر BUILD_INSTRUCTIONS.md). ما يلي هو خطة التثبيت والقيود المؤكدة تصميميًا.

## مسارات التثبيت الشرعية
| المسار | المتطلبات | ملاحظات |
|---|---|---|
| **Apple Developer (مدفوع)** + TestFlight/تثبيت مباشر | حساب مطور $99/سنة، Provisioning لـ `com.wezcrypt.telegram` وامتداداته | الأنظف: توقيع سنة كاملة، App Groups وPush Capabilities كاملة |
| **Xcode Personal Team (مجاني)** | Apple ID عادي + Mac | توقيع 7 أيام، حد 3 تطبيقات، بعض الـ Capabilities مقيدة (قد تنكسر App Groups/Push) — مناسب لأول تجربة |
| **AltStore / SideStore** | إعادة توقيع دورية بالـ Apple ID | يعيد التوقيع تلقائيًا عند الاتصال؛ الامتدادات (Notification/Share/Widget) قد تُجرَّد أو تتعطل حسب حدود الـ Free Provisioning |
| **Sideloadly** | Apple ID + كابل | مشابه؛ صلاحية 7 أيام للحساب المجاني |

## قيود يجب أن تعرفها قبل التثبيت
1. **لن يعمل البناء الموزّع بدون `api_id` خاص بك** — تسجيل الدخول برقم الهاتف يعتمد على الـ `api_id` المسجل لدى Telegram لهذا التطبيق.
2. **Push Notifications**: العميل يسجّل Device Token لدى خوادم Telegram (`account.registerDevice`)، لكن الإيصال الفعلي عبر APNs مرتبط بشهادات/Provisioning الـ Bundle ID الجديد وبقبول Telegram للإشعارات لعملاء الطرف الثالث — **غير مُتحقق حتى اختبار جهاز حقيقي**؛ لا تدّعِ عمل الإشعارات قبل ذلك. Notification Service Extension يحتاج App Group مطابقًا للـ Bundle Prefix.
3. **مكالمات/قنوات/بوتات/ملصقات/Secret Chats**: كلها وظائف Upstream لم تُعدَّل؛ عملها يعتمد على نجاح البناء لا على Patch هذا المشروع.
4. **Telegram Premium**: شراء Premium داخل عميل خارجي يتم عبر قنوات Telegram الرسمية (Stars/bot) لا عبر Apple IAP الخاص بالرسمي (`premium_iap_product_id` تُرك فارغًا في الإعداد عمدًا — لا محاولة لفتح مزايا مدفوعة ولا لجمع مدفوعات).
5. **الاسم والأيقونة**: اسم الشاشة «WezCrypt» (قيود §2.3)، ويلزم تصميم أيقونة خاصة — لا تستخدم أيقونة Telegram الرسمية في أي بناء توزيعي.
6. **التعايش**: Bundle ID مختلف يعني تثبيتًا مستقلًا بجانب Telegram الرسمي، بقاعدة بيانات وجلسة منفصلتين — سجّل دخولك من جديد.

## خطوات التثبيت عبر AltStore/SideStore (بعد توفر IPA)
1. ثبّت AltServer/SideStore حسب وثائقه الرسمية واربط iPhone بنفس الشبكة/الكابل.
2. اختر `WezCryptTelegram.ipa` للتثبيت، وأدخل Apple ID عند الطلب (داخل أداة التثبيت نفسها فقط).
3. من iPhone: الإعدادات ← عام ← VPN وإدارة الجهاز ← ثق بملف المطور.
4. افتح التطبيق وسجّل دخولك برقم هاتفك؛ فعّل 2FA من الإعدادات إن لم تكن مفعّلة.
